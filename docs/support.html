Before sending a report

Include the CPU Bloom version, whether you use the Store/MSIX or portable edition, your Windows version, GPU model, and steps to reproduce the issue. A screenshot is helpful if you choose to share one. Remove personal details first; do not include passwords, access tokens, identity documents or entire user-profile folders.

Common questions

Where did the window go?

Minimizing normally hides CPU Bloom in the system tray, including the tray's hidden-icons area. Double-click the flower icon to restore it, or right-click and choose Show. Launching the normal app again also restores its existing window. Right-click the tray icon and choose Quit to exit completely.

How do I resize the window or change the theme?

Drag the bottom-right grip to resize. The normal window remembers its size. Open Menu in the top-right corner for themes, Preferences and tray controls. Press N to cycle themes, H to toggle readings, and P or Space to pause animation.

How do I control startup?

Open Menu → Preferences → Start with Windows. New installations default to off. When enabled, login starts the app in the tray, provided a tray icon is available. The MSIX edition respects Windows Settings → Apps → Startup and organization policy. If Windows has disabled startup, re-enable it there when permitted. For the portable edition, untick and retick the option after moving its folder.

Why is GPU temperature missing?

The Windows GPU counter provider reports the busiest GPU engine's activity; it does not currently report GPU temperature or GPU memory. Supported Windows drivers can expose activity for AMD, Intel and NVIDIA adapters. Availability varies by driver; a missing reading is not a zero reading. The portable edition’s optional NVIDIA fallback may provide additional metrics when available. CPU temperature is currently unavailable in the Windows build.

Does CPU Bloom keep rendering while minimized?

Rendering, animation decoding and GPU collection pause when minimized or hidden. CPU and RAM sampling slows to once every two seconds. Restoring wakes the app immediately. Cached graphics remain in memory for quick restoration. A visible window continues rendering even if another window covers it.

Where are screenshots and preferences?

Press S to save a screenshot in your Windows Pictures folder under CPU Bloom. The folder may be redirected to OneDrive. Portable preferences are in %APPDATA%\CPU Bloom. The Store edition uses Windows package-local data. Preferences can export a ZIP from the portable edition and import it into the Store edition; startup consent is not copied.

What does the Windows build require?

The MSIX target is Windows 11 x64 with a compatible OpenGL graphics driver. Java is bundled. The portable folder must stay together: moving only its EXE breaks access to the runtime, libraries and assets. See the project README for platform and installation details.

Windows blocks a local test build

The repository's portable and local-test builds are unsigned development builds, not Microsoft Store releases. Do not disable Windows security protections to install them. Contact the developer or wait for the Store release. Store submission is currently in preparation.
