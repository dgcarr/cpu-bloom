# CPU Bloom privacy policy — publication draft

CPU Bloom displays CPU utilization, processor information, memory usage, and optional GPU metrics locally on your Windows computer. It reads these values through Windows interfaces and, when available, NVIDIA's installed command-line utility.

CPU Bloom has no account, advertising, analytics, telemetry upload, or cloud service. System readings are processed locally. Preferences, window dimensions, and bounded animation caches are stored in your Windows user profile. Screenshots are written to your Pictures folder only when you request them. Screenshots can contain displayed hardware information and readings; sharing them is your choice.

Start with Windows is optional and off by default. You can change it in CPU Bloom or Windows Startup settings. Importing settings from a portable installation is optional and does not enable startup or delete that installation.

Uninstalling the Store application removes its managed application data according to Windows behavior. Screenshots you exported and a separate portable installation are not removed. Microsoft Store and Windows may process their own diagnostic information under Microsoft's policies; this policy describes CPU Bloom's own behavior.
